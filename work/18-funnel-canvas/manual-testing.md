# Ручна перевірка — 18-funnel-canvas

Те, що агент без живого браузера/бота не відтворює. Перевіряти на екрані **≥1024px**.
Автоматику (тести, build, i18n, backend round-trip + рушій) уже пройдено — див. `smoke.md`.

## 1. Рендер і розкладка

- [ ] Відкрити наявну воронку → canvas рендерить **усі** вузли: кроки, стартовий вузол (якщо є `on_start`), event-тригер-вузли, замітки.
- [ ] Воронка **без збережених координат** → авто-розкладка **dagre**, потім `fitView` вписує граф у вʼюпорт (не порожній екран, не злиплося в кутку).
- [ ] Відключені підпотоки / сироти (Phase-8 чернетки) теж видно — не зникають, не «з'їдаються» розкладкою.
- [ ] **Zoom / pan** працюють (колесо + перетягування полотна).

## 2. Пересування та збереження координат

- [ ] Перетягнути вузол → відпустити → перезавантажити сторінку → вузол **на тому ж місці** (координати збереглися).
- [ ] Перетягнути **тригер-вузол** і **замітку** → reload → позиції теж збереглися (це місце, де були 2 баги silent-drop — варто пройти уважно).

## 3. Малювання ребер (draw-to-connect)

- [ ] Від дефолтного виходу `next` провести ребро до іншого вузла → зберегти → reload → ребро на місці.
- [ ] Від виходу **кнопки** провести ребро → перевірити, що проставився `Button.targetStepId` саме цієї кнопки.
- [ ] Від виходу **таймауту** провести ребро.
- [ ] Спробувати провести ребро до **нового (ще не збереженого)** вузла → має бути неможливо (спершу зберегти, щоб дістати `id`).
- [ ] Видалити ребро → поле стає порожнім (а не `""`); якщо ціль зникла — ребро підсвічується як **бите**.

## 4. Стартовий вузол `on_start`

- [ ] Воронка лише з event-входами → стартового вузла **немає**.
- [ ] Додати `on_start` з палітри → зʼявляється стартовий вузол; повторний пункт у палітрі **задізейблений**.
- [ ] Ребро стартового вузла визначає крок входу; видалити **лише ребро** → `on_start` без входу → **бите ребро** (підсвічене; активація дає 422).
- [ ] Видалити **сам стартовий вузол** → `on_start`-вхід прибирається з воронки.

## 5. Палітра, видалення, бокова панель

- [ ] Палітра містить **рівно наявні типи** (MESSAGE, DELAY, ADD_TAG, REMOVE_TAG, SET_CUSTOM_FIELD, EMIT_EVENT, SUBSCRIBE_TO_FUNNEL, SET_KEYBOARD, CLEAR_KEYBOARD) + тригер + замітка. Нових виконавчих типів немає.
- [ ] Додати вузол з палітри → він зберігається (дістає `id`), далі його можна зʼєднувати.
- [ ] Видалити вузол, на який вказують ребра → попередження «**N звʼязків буде відключено**», після підтвердження ребра авто-чистяться.
- [ ] Клік по вузлу-кроку → бокова панель відкриває наявну форму; **вибору таргетів через SearchableSelect немає** (його заміняють ребра); інші поля редагуються як раніше.
- [ ] Відредагувати поле кроку в боковій панелі → reload → **позиція вузла НЕ злетіла** (баг MAJOR-1, виправлено — перевірити).

## 6. Замітки (Decision B)

- [ ] Додати замітку з палітри → клік по ній → у боковій панелі **редактор тексту** (textarea).
- [ ] Ввести текст → зберегти → reload → текст на місці.
- [ ] Ввести `<img src=x onerror=alert(1)>` як текст → **жодного alert / картинки**, показується як звичайний текст (екранування).
- [ ] Замітка **не впливає на виконання** воронки.

## 7. Read-only поверхні (Decision 2 + Decision A)

- [ ] Вертикальний **список кроків** — лише перегляд, без редагування/додавання/видалення.
- [ ] **Панель тригерів** — теж read-only (редагування тригерів тепер тільки через canvas). Якщо очікував, що вона лишиться редагованою — скажи, відкотимо.

## 8. Cross-funnel і биті ребра

- [ ] `SUBSCRIBE_TO_FUNNEL`, що вказує в **іншу** воронку → показано **бейджем-виходом**, а не ребром.
- [ ] Бите ребро (ціль видалена) підсвічується; спроба активувати воронку з битим ребром → 422 `funnel_broken_edge`.

## 9. Наскрізний потік (бот)

- [ ] Зібрати воронку «меню з кнопками → гілки», намалювати ребра, **активувати**.
- [ ] У боті `/start` → підписник заходить у крок, на який вказує ребро стартового вузла (а не в `array[0]`).
- [ ] Пройти гілки: натискання кнопок веде в намальовані цілі; вузол **без ребра `next`** = **кінець гілки** (не провалюється в наступний крок за порядком).
- [ ] «Test for me» (testRun автора) теж заходить у правильний крок входу.

## 10. Локалі / SSR

- [ ] Перемкнути uk/en → підписи canvas (палітра, кнопки, попередження, стартовий вузол, редактор замітки) показуються активною локаллю, без порожніх ключів.
- [ ] Сторінка редактора відкривається без помилки `window is not defined`.

---

**Якщо щось не так** — кажи конкретний пункт, зроблю ad-hoc фікс із ревʼю (команда ще активна, checkpoint не видалений).
