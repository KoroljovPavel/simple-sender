# Task 1: Infrastructure setup

## Required Skills

Before starting, load:
- `/skill:infrastructure-setup` — [SKILL.md](~/.claude/skills/infrastructure-setup/SKILL.md)

## Description

Fix two broken env var bindings in `application.properties` that have existed since Epic 01 (`MONGODB_URI` and `REDIS_URL` were never wired). Add Mailpit to `infra/docker-compose.yml` for local email testing. Add all new Gradle dependencies required by Epic 02: `spring-session-data-mongodb`, `spring-boot-starter-mail`, `spring-boot-starter-validation`, `jobrunr-spring-boot-3-starter`, Testcontainers suite. Add corresponding properties to `application.properties` and a new `application-test.properties` for Testcontainer overrides.

This task is the foundation for all Wave 2+ tasks — without correct deps and properties, nothing compiles or connects.

## What to do

1. Fix `application.properties`: bind `MONGODB_URI` → `spring.data.mongodb.uri=${MONGODB_URI}` and `REDIS_URL` → `spring.data.redis.url=${REDIS_URL}`.

2. Add session properties to `application.properties`:
   - `spring.session.store-type=mongodb`
   - `spring.session.mongodb.collection-name=sessions`
   - `server.servlet.session.cookie.http-only=true`
   - `app.session.ttl-default-hours=${SESSION_TTL_DEFAULT_HOURS:24}`
   - `app.session.ttl-remember-me-days=${SESSION_TTL_REMEMBER_ME_DAYS:30}`

3. Add mail properties to `application.properties`:
   - `spring.mail.host=${MAIL_HOST:localhost}`
   - `spring.mail.port=${MAIL_PORT:1025}`
   - `spring.mail.username=${MAIL_USERNAME:}`
   - `spring.mail.password=${MAIL_PASSWORD:}`
   - `app.mail.from=${MAIL_FROM:noreply@botfunnel.local}`
   - `app.support-email=${SUPPORT_EMAIL:support@botfunnel.local}`
   - `app.url=${APP_URL:http://localhost:3000}`

4. Add JobRunr + Super Admin properties to `application.properties`:
   - `org.jobrunr.background-job-server.enabled=true`
   - `org.jobrunr.dashboard.enabled=false`
   - `app.super-admin.email=${SUPER_ADMIN_EMAIL:}`
   - `app.super-admin.password=${SUPER_ADMIN_PASSWORD:}`

5. Add new Gradle deps and JaCoCo to `backend/build.gradle`:
   - Add `id 'jacoco'` to the `plugins` block.
   - Add the following configuration block (so `jacocoTestReport` runs after tests):
     ```groovy
     jacocoTestReport {
         dependsOn test
     }
     ```
   - Add to the `dependencies` block:
     ```
     implementation 'org.springframework.session:spring-session-data-mongodb'
     implementation 'org.springframework.boot:spring-boot-starter-mail'
     implementation 'org.springframework.boot:spring-boot-starter-validation'
     implementation 'org.jobrunr:jobrunr-spring-boot-3-starter:7.3.2'
     testImplementation 'org.testcontainers:mongodb'
     testImplementation 'org.testcontainers:junit-jupiter'
     testImplementation 'ch.martinelli.oss:testcontainers-mailpit:1.3.1'
     ```

6. Create `backend/src/test/resources/application-test.properties` (new file). Activates the `test` spring profile; actual Testcontainer URIs are injected via `@DynamicPropertySource` in `AbstractIntegrationTest`.

7. Add Mailpit service to `infra/docker-compose.yml`:
   ```yaml
   mailpit:
     image: axllent/mailpit:latest
     ports:
       - "127.0.0.1:8025:8025"
       - "127.0.0.1:1025:1025"
     restart: unless-stopped
   ```

8. Update `.env.example` with all new vars: `SESSION_TTL_DEFAULT_HOURS`, `SESSION_TTL_REMEMBER_ME_DAYS`, `SUPER_ADMIN_EMAIL`, `SUPER_ADMIN_PASSWORD`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM`, `SUPPORT_EMAIL`, `APP_URL`. Remove `JWT_SECRET`, `JWT_ACCESS_TTL_MINUTES`, `JWT_REFRESH_TTL_DAYS` if present.

## Details

**Files:**
- `backend/build.gradle` — add 7 new deps in correct sections (implementation/testImplementation)
- `backend/src/main/resources/application.properties` — fix MongoDB/Redis bindings, add session/mail/jobrunr/super-admin properties
- `backend/src/test/resources/application-test.properties` — new, minimal (spring profile activation)
- `infra/docker-compose.yml` — add mailpit service block
- `.env.example` — sync new vars, remove JWT vars

**Dependencies:**
- None — this is wave 1 infrastructure

**Edge cases:**
- JobRunr dependency group is `org.jobrunr`, NOT in Spring Boot BOM — needs explicit version. Check Maven Central if 7.3.2 is not current.
- `testcontainers-mailpit:1.3.1` — pinned version, do NOT use a range
- Mailpit ports MUST be bound to `127.0.0.1` only (not exposed to network)
- `spring.data.mongodb.auto-index-creation=false` — must stay false globally; spring-session creates its TTL index on `sessions` independently

**Implementation hints:**
- `spring-session-data-mongodb`, `spring-boot-starter-mail`, `spring-boot-starter-validation` are all in Spring Boot BOM — no version needed
- In `.env.example`, show example values (not real ones): `MAIL_HOST=localhost`, `SUPER_ADMIN_EMAIL=admin@example.com`
- For Redis Testcontainer, use `GenericContainer<>("redis:7-alpine").withExposedPorts(6379)` — there is no dedicated Redis Testcontainers module. Override `spring.data.redis.url=redis://localhost:{container.getMappedPort(6379)}` via `@DynamicPropertySource` — this matches the URL-based production config. Do NOT override `spring.data.redis.host`/`spring.data.redis.port` as those have no effect when `spring.data.redis.url` is active.
