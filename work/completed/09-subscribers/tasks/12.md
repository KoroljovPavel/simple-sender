For each, locate the implementing code site and assert the implementation faithfully reflects the decided choice. **Severity calibration:**
- **Critical** — blocks merge. Examples: a Decision is contradicted in a way that violates a user-spec AC; a heavy singleton is `new`-ed in a request handler (creates per-request cost); `requireOwned` missing on an endpoint that touches owner data; secret/PII logged in a fail-open WARN path.
- **Major** — should fix before merge. Examples: a Decision drift that does not violate AC but creates inconsistency (e.g. one of three rate-limit buckets does not log the greppable constant); a Request record missing `@JsonIgnoreProperties(ignoreUnknown = true)`; cascade order in `ProjectHardDeleteJob` swapped relative to Decision 8.
- **Minor** — fix in follow-up commit. Examples: commented-out code block; a `TODO` marker without owner/issue link; package-layout deviation from `architecture.md`.
- **Info** — FYI, no action required. Examples: a Decision deliberately deferred and that deferral is correctly reflected; a noted improvement opportunity for a future epic.
